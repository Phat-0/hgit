# Danh mục hành chính Việt Nam

Dữ liệu gồm 34 tỉnh/thành và 3.321 phường/xã/đặc khu sau sắp xếp năm 2025, được rút gọn từ `data/hierarchy.json` của [Open Admin Data](https://github.com/open-admin-data/vietnam-administrative-divisions).

Giấy phép nguồn: **CC BY 4.0**. Bản dữ liệu được đưa trực tiếp vào dự án để dropdown hoạt động không cần gọi API bên ngoài. Tên hiển thị giữ nguyên trường `name.local` của nguồn; mã giữ nguyên `id`.

Ngày truy xuất: 2026-10-25. Khi có cập nhật hành chính mới, cần đối chiếu và cập nhật file `don-vi-hanh-chinh.json`.
